# Python Basics Learning Lab

A step-by-step Python curriculum built folder by folder, from first script to a command-line inventory tool. Theme: the **Warehouse Management Learning Lab**.

**Language:** Python 3.10+ &nbsp;|&nbsp; **Goal:** real understanding plus a portfolio on GitHub.

## How each topic is organized

- **Intermediate files:** correct syntax and basic organization.
- **Advanced files:** better structure, realistic content, bad-input handling.
- **Topic `README.md`:** purpose, what improved, what I learned, known issues.
- Several files of the same level are numbered (for example `intermediate1.py`, `intermediate2.py`).

## Run an exercise

```
git clone https://github.com/azizab-aziz/python-basics-learning-lab.git
cd python-basics-learning-lab
python 01-setup/intermediate1.py
```

On Windows, use `py` instead of `python` if `python` opens the Microsoft Store.

## Conventions

- Folder = topic, filename = level. Lowercase, hyphens, no spaces.
- Shared dataset: SKUs LAP-001, MON-001, KBD-001, SCN-001, MSE-001, PRT-001, locations like A-01, currency TND.
- Progress journal: see [learning-log.md](learning-log.md).
